## 项目说明

1. **项目定位**：用于存放计算机科学与技术专业《操作系统》(Operating System) 课程的学习笔记。
2. **渲染与部署**：使用 MkDocs (Material for MkDocs 主题) 进行渲染，并通过 GitHub Actions 部署在 GitHub Pages 上。
3. **目录结构规范**：
   - `docs/`：**所有** Markdown 笔记源文件的唯一存放目录，所有新增或修改的笔记都必须保存在该目录下，绝不允许在项目根目录下生成笔记。
   - `Slides/`：存放上课课件、教材及实验相关的 PDF 文件。
   - `mkdocs.yml`：站点全局配置文件。每次新增笔记文件后，需同步提醒更新其 `nav:` 导航配置。
   - 静态资源：笔记中引用的图片统一保存在 `docs/images/`，并在文档中使用相对路径引用。

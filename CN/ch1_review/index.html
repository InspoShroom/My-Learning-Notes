    计算机网络 第 1 章：核心知识点复习

    一、 网络宏观架构与边缘 / 核心

    1. 网络的地域分类与边缘/核心划分

    1. 按地域规模划分，PAN、LAN、MAN、WAN 分别代表什么？请各举一个生活中的典型例子。
    2. 什么是网络边缘（Network Edge）？它由什么构成？核心功能是什么？
    3. 什么是网络核心（Network Core）？其核心任务是什么？主要由哪些设备构成？

    2. 接入网（Access Network）与最后一公里

    1. “接入网”到底是一个动作过程，还是一种客观的物理/逻辑存在？用“公路交通系统”如何形象比喻它？
    2. 为什么说光纤到户（FTTH）属于无源光网络（PON）？这里的“无源”具体是指哪一部分无需供电？
    3. 在 PON 架构中，OLT（光线路终端） 和 ONT（光网络终端/光猫） 分别部署在什么物理位置？它们各自的核心职责是什么？
    4. 为什么 OLT 在上行方向（各家庭光猫向机房发光时）必须采用 TDMA（时分多址） 进行严格调度？

    3. 数据交换方式与多路复用

    1. 简述电路交换（Circuit Switching）的主要特点及其最大缺点（为什么无法应对互联网广泛存在的突发流量？）。
    2. 什么是分组交换（Packet Switching，包交换）？相比传统的“报文交换（Message Switching）”，为什么把大报文拆分成小分组可以大幅降低整个传输过程中的存储转发（Store-and-Forward）时延？
    3. 解释 FDM（频分多路复用） 与 TDM（时分多路复用） 的英文全称与本质切分维度的区别；什么是统计时分复用（STDM）？

    4. 路由与转发（网络核心两大功能）

    1. 为什么说路由（Routing）是全局操作，而转发（Forwarding）是本地操作？
    2. 路由属于哪一个平面（控制平面还是数据平面）？转发属于哪一个平面？它们之间通过什么核心数据结构建立联系？

    二、 分层模型与协议体系结构

    5. 为什么需要分层与参考模型？

    1. 什么是网络协议的“三要素”？请分别解释语法、语义和时序。
    2. 计算机网络为什么一定要采用分层体系结构？它带来的三大核心工程优势是什么？（以 Wi-Fi 升级到 Wi-Fi 6 无需修改微信代码为例说明）。
    3. 为什么说“协议是水平的，服务是垂直的”？什么是对等实体（Peer）？

    6. OSI 7 层 vs TCP/IP 4 层 vs 五层教学模型

    1. OSI 7 层从下到上各层的标准名称是什么？每一层对应的传输数据单元（PDU）分别叫什么（Bit, Frame, Packet, Segment, Message）？
    2. 数据链路层（L2） 与 网络层（L3） 的根本分工区别是什么？（提示：Hop-to-Hop 邻居传输 vs Host-to-Host 端到端传输）。
    3. 【核心考点】 既然每块网卡在出厂时都有全球唯一的 MAC 地址，为什么在网络层还需要单独分配 IP 地址？（请从路由聚合/层次化寻址与异构网络屏蔽两个角度说明）。
    4. 传输层（L4） 的核心作用是什么？为什么有了 IP 地址定位主机之后，还必须依赖端口号（Port）？
    5. 简述 TCP（面向连接、可靠） 与 UDP（无连接、不可靠） 的核心区别及各自适用的典型业务场景。
    6. 为什么 OSI 七层模型在工业界失败了，而 TCP/IP 取得了最终事实标准的胜利？
    7. 解释 TCP/IP 的“端到端原则”（为什么说是“简单网络 & 聪明终端”？）以及著名的“沙漏模型”（IP over everything, Everything over IP）。
    8. 当主机 A 向主机 B 发送数据经过局域网交换机和多台路由器时：
      • 交换机会解封装到哪一层？
      • 路由器会解封装到哪一层？为什么路由器在转发前必须剥离并重新封装数据链路层帧头？

    三、 套接字网络编程（Socket API）

    7. 套接字本质与地址结构

    1. 套接字（Socket） 的本质是什么？它位于哪两层之间？为什么它的英文原意叫“插座”？
    2. 在 Linux 系统中，“一切皆文件”是如何在套接字上体现的？什么是套接字描述符（sockfd）？
    3. 为什么需要定义通用的 struct sockaddr（虚父类）和 IPv4 专用的 struct sockaddr_in（子类）？代码中是如何通过强制类型转换配合使用的？
    4. 什么是大端字节序（网络字节序）和小端字节序？为什么在给 sin_port 赋值时必须调用 htons()？
    5. 32 位 IPv4 地址在计算机底层是以什么形式存储的？inet_pton() 函数的作用是什么？

    8. UDP 套接字通信流程

    1. 为什么基于 UDP 的通信不需要调用 listen()、connect() 和 accept()？
    2. 详细说明 sendto() 和 recvfrom() 的每个参数含义，为什么发送必须显式传入目标地址 to，接收必须传入出参 from？
    3. 在 UDP 回音服务端中，服务端在 bind() 时将 IP 设为 htonl(INADDR_ANY) 代表什么含义？为什么整个 UDP 服务端只需要一个套接字就能为多个不同的客户端服务？

    9. TCP 套接字通信流程

    1. 【核心考点】 在 TCP 服务器中，为什么必须同时存在监听套接字（listenfd）与已连接套接字（connfd）？用“酒店大堂迎宾员与包厢服务员”如何通俗比喻？
    2. 解释 listen(socket_fd, backlog) 中 backlog 参数的含义。
    3. 解释客户端调用 connect() 时底层发生了什么？为什么该调用是阻塞的？
    4. accept() 函数是从哪里取出连接的？它的返回值是什么？
    5. 一旦 TCP 连接建立完毕，双方为什么可以直接使用普通文件读写调用 read() 和 write() 进行通信？服务端如何知道客户端已经主动断开了连接（触发 EOF）？

    四、 网络度量单位与底层辅助机制

    10. 速率、带宽与四大时延

    1. 【单位陷阱】 存储计算（Byte）与网络传输（bit）在单位大小写和 \(K/M/G\) 进制换算上有何关键不同？为什么办理了 \(100\text{ Mbps}\) 的宽带，实际最大下载速度只有约 \(12.5\text{ MB/s}\)？
    2. 什么是交换机的线速转发？在同样带宽负载下，为什么大包比小包更容易实现线速转发？
    3. 详细写出网络总时延的四个组成部分：
      • 处理时延（\(d_{\text{proc}}\)）：因何产生？
      • 排队时延（\(d_{\text{queue}}\)）：因何产生？
      • 传输时延 / 发送时延（\(d_{\text{trans}}\)）：计算公式是什么？取决于什么？
      • 传播时延（\(d_{\text{prop}}\)）：计算公式是什么？取决于什么？
    4. 简述时延带宽积的物理意义，为什么它被形象地称为“以比特为单位的链路长度”或“充满管道的比特数”？

    11. 网络辅助协议与运行机制

    1. 什么是 ICMP 协议？它属于哪一层？为什么说它是网络层的“侦察兵与报错员”？
    2. ping 命令工作在第几层？它使用了 TCP 还是 UDP 协议？黑框输出中的 icmp_seq、time (RTT) 以及 TTL 分别表示什么？
    3. 什么是 ARP 协议？它的核心使命是什么？它是如何通过“广播请求（大喇叭）”与“单播应答（私信）”建立起 IP 与 MAC 地址映射的？什么是 ARP 缓存表？
    4. 简述设备关闭 Wi-Fi 或设备损坏时，路由器如何通过 DHCP 租期机制 和 ARP 探测 回收 IP 地址。
